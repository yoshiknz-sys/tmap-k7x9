軸: 横・縦それぞれ 3M / 20D / 15D / 10D / 5D / 1D / 当日 を選択（対数風スケール・表示中の銘柄に自動ズーム）。 象限しきい値は軸の期間に連動（3M±5.0% / 20D±2.5% / 15D±2.0% / 10D±1.5% / 5D±1.0% / 1D・当日±0.5%）。
当日=最新バー÷1本前（ザラ場中は未確定・大引けまで動く）／ 1D=1本前÷2本前（確定値。MACD-V「前日確定」と同じ時点）。 時点ボタンをずらすと両方が一緒にずれます。
全銘柄: 対象全銘柄を並び替え順に一覧表示します（業種でまとめずフラットに表示）。 リストは100件ずつ追加読み込み。点が多いためチャートのコードラベルは省略されます（「ラベル」ボタンで銘柄名表示）。
並び替え: 第1〜第5のプルダウンで優先順に指定します（第1が最優先）。各段の［↓大→小 / ↑小→大］で向きを切替。 「— 指定なし —」でその段を解除すると下の段が繰り上がります。既定は第1＝当日の降順。
20SMA乖離＝(終値÷20日単純移動平均−1)×100。※★整列の判定はEMA20なので数値は一致しません。
Hist＝「MACD-V − Sig = 差分」の右辺。Pine Scriptの hist = macdV - Signal と同じ値で、 TradingViewのヒストグラムの棒の高さに対応します（勢いの加速度）。連続＝①②③の連続本数。 どちらも「該当（✔）が先、非該当が後」の2段構えで、グループ内が同じ基準で並びます。 ボタンの↓が大きい順、↑が小さい順です（↑では非該当が先頭に来ます）。 業種一覧では ★・乖離・連続はいずれも該当数で並びます。 同点は勢い順に並びます。
四隅のラベル（リーダー／押し目／⚠反発／下降）はタップで絞り込み。 選択中は「●」が付き、同じラベルを再タップすると「全て」に戻ります。
ゾーン: 横軸3段×縦軸3段の9分類。しきい値超=強 / ±しきい値内=中間 / しきい値割れ=弱。
　横強→ リーダー（縦強）/ 継続（縦中間）/ 押し目（縦弱）
　横中間→ 点火（縦強）/ 中立（縦中間）/ 失速（縦弱）
　横弱→ ⚠反発（縦強）/ 弱（縦中間）/ 下降（縦弱）
MACD-V: ①MACD-V右上がり ②Signal右上がり ③MACD-V>Signal ④縦軸リターンがマイナス。 ①②③はN本連続で成立が必要（1/2/3/5から選択・既定3）。1本だけの上向きを除外します。 判定バーは「前日確定／当日終値」で切替。前日確定なら当日の値動きで①②③が動かないので、 ザラ場中に見ても大引けに見ても同じ銘柄が出ます（縦軸「当日」と組むと「昨日勢いが転換・今日は前日終値割れ」）。 当日終値は引け後に翌日寄付を狙う用。 MACD-V=(EMA12−EMA26)/ATR26×100、Signal=EMA9。ATRはRMA(Wilder)平滑・TradingView版と同一。 勢いが上向きに転じているのに株価が下がっている状態を拾う枠。
★整列: EMA60>EMA120>EMA200 かつ 終値がEMA20の±3.0%以内。トレンドが揃い、かつ短期の伸びきりが小さい状態。
⚠弱→反発 は長期がマイナスの銘柄の短期反発です。下降トレンド中の反発は継続性が低く、期間中の期待値は他の象限より低くなりやすい枠です。
